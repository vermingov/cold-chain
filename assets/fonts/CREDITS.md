# Fonts

`im-fell-english.ttf` and `im-fell-english-italic.ttf`: IM FELL English Roman and Italic, (c) 2007 Igino Marini
(www.iginomarini.com), SIL Open Font License 1.1. The same fonts the TS game uses from vendor/fonts (WOFF2 there),
unpacked to TrueType unchanged for the Bevy port, which reads TTF/OTF only. Used for the HUD and the numbers on the
hall's walls.
